# Avaliação de Qualidade de Software - Aplicação de IA Generativa

## Sobre esta Atividade

Esta é a **Atividade 2 (AV2) — Missão Contexto Confiável**, com foco na missão **D: Contexto sob Pressão**. O objetivo é verificar, com testes e evidências, se a aplicação de IA generativa responde com base em contexto adequado, resiste a instruções maliciosas e apresenta resultados verificáveis.

A análise compara o comportamento do sistema diante de contexto correto, ausente, irrelevante e conflitante, avalia diferentes versões de prompt (P1, P2 e P3), audita fontes e citações e propõe melhorias para os achados mais críticos.

**Projeto Avaliado:** AnythingLLM <br />

## Como Replicar esta Avaliação

### Passos

1. **Clone este repositório**
```bash
   git clone https://github.com/Arielsnts/QS_2026-2_AnythingLLM_atividade2
   cd QS_2026-2_anythingLLM_atividade2
```

2. **Consulte a documentação técnica**
   - Leia os arquivos em `docs/` na ordem sugerida
   - Revise as evidências em `evidencias/`
   - Consulte os casos de teste em `docs/05-testes.md`

3. **Replique os testes**
   - Use os prompts versionados em `02-lab-contexto-prompts.md` (P1, P2 e P3)
   - Siga os cenários de contexto
   - Registre respostas da IA e compare com nossos resultados
   - Documente desvios ou novas descobertas

4. **Valide os achados**
   - Revise o plano de melhoria em `07-plano-melhoria.md`
   - Teste as recomendações propostas com os mesmos casos de teste
   - Compare com seu contexto de uso
